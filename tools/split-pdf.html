How to use Split PDF

Three ways to break a PDF apart.

  1. 1

    Upload the PDF

    The file is opened locally and the tool reports the total number of pages.

  2. 2

    Choose a mode

    “Extract pages” gathers your ranges into a single PDF. “One file per range” writes each comma-separated range to its own file. “Every page” splits the document completely.

  3. 3

    Enter the pages

    Type a range such as 1-3, 5, 7-9. Reversed ranges and duplicates are handled for you.

  4. 4

    Split and download

    One file downloads directly; multiple files arrive together as a ZIP archive.
