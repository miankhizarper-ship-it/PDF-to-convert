How to use Merge PDF

Combine PDFs in the exact order you want.

  1. 1

    Add your PDFs

    Drop two or more PDF files onto the zone. Each one is read locally to show how many pages it has.

  2. 2

    Set the order

    Drag a row to a new position, or use the up/down buttons. The order you see is the order of the merged document.

  3. 3

    Merge

    Press “Merge PDFs”. Pages are copied into a new document — nothing is re-rendered, so text stays selectable and quality is untouched.

  4. 4

    Download

    The combined PDF is saved to your device with a name you can change afterwards.
