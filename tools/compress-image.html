How to use Compress Image

Balance quality against file size in seconds.

  1. 1

    Add images

    Drop one or many JPG, PNG or WEBP files. Thumbnails and original sizes are listed straight away.

  2. 2

    Set quality and limits

    Drag the quality slider and optionally cap the width or height. Aspect ratio is always preserved.

  3. 3

    Compress

    Each image is re-encoded on a canvas. You will see the new size and the percentage saved next to the original.

  4. 4

    Download

    Save images one at a time, or take the whole batch as a ZIP.
