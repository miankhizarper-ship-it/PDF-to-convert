How to use Text to PDF

From plain text to a formatted PDF.

  1. 1

    Write or import

    Type straight into the box, or drop a .txt / .md file onto the zone to fill it.

  2. 2

    Style the page

    Choose a font, size, line spacing, alignment, page size, orientation and margins.

  3. 3

    Watch the preview

    The preview uses the same layout engine as the PDF, so line breaks and page splits match the output.

  4. 4

    Create the PDF

    Press “Create PDF” — text is paginated locally and downloaded as a proper, searchable PDF.
