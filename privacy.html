Privacy

The short version: your files never leave your device. There is no upload, no server-side processing and no copy of your documents anywhere but your own machine.

What happens when you use a tool

  1. You pick a file. Your browser reads it from disk into memory through the standard file input.
  2. A JavaScript library in the page converts, merges, splits or compresses it — on your CPU.
  3. The result is turned into a download in your browser and saved to your device.
  4. When you close the tab, the memory is released. Nothing was transmitted.

What we never do

  • We never upload your files — there is no backend service to upload them to.
  • We never store, cache or index your documents.
  • We never require an account, an email address or a payment method.
  • We never run advertising or cross-site tracking scripts.
  • We never read the contents of your files for any purpose other than the conversion you asked for.

What does leave your browser

Two things, neither of them your documents:

  • Static assets. The page loads its stylesheet and the Inter typeface from Google Fonts, and the conversion libraries (mammoth.js, SheetJS, jsPDF, pdf-lib, pdf.js, JSZip, qrcode-generator) from the jsDelivr CDN. Those requests carry the same information any website request does — your IP address and browser details — but never your file contents. Versions are pinned, so the code you run does not change without a new release of this site.
  • Hosting logs. Wherever you host this site records ordinary web-server logs (IP address, requested page, timestamp) for security and uptime. Those logs contain no file data because no file is ever sent.

Local storage

The only thing written to your browser's local storage is your theme preference (light or dark) under the key filetools-theme. A one-off search term may be kept in session storage purely to hand it from the header search box to the home page grid; it is deleted immediately and never sent anywhere.

Verifying it yourself

Open your browser's developer tools → Network tab, filter by “Fetch/XHR”, and use any tool. You will see the CDN requests for the libraries and nothing else. No request will contain your file.

Because processing happens in memory, confidential documents are a good fit — but a browser tab is still your own machine. Keep your operating system and browser up to date, and remember that anything you download lands in your downloads folder like any other file.

Changes to this policy

If this ever changes, the update will be published on this page before it takes effect. As long as the site has no backend, there is simply no mechanism by which your files could be collected.
